# simple_live_app

基于核心库实现的Flutter APP客户端。

## 直播回放

斗鱼直播间可通过“更多 → 查看回放”进入回放列表。打开列表时会暂停当前直播流，
离开回放列表后恢复直播；回放播放器支持进度跳转、倍速、清晰度与全屏。
桌面端使用宽屏布局，并在退出页面前停止和释放播放器。

回放默认使用最高清晰度：接口返回的清晰度是 JSON 对象，键顺序由服务端决定，
因此按各档位的 level 降序排列后再取第一项，而不是沿用键顺序。

## 直播流恢复

直播流中断时会先重载当前线路、再切换备用线路，最后重新向平台获取地址。
新地址需连续播放 10 秒才视为恢复成功；连续 3 次新地址仍失效后停止自动重开，
并提示手动刷新，避免播放器反复刷新。
